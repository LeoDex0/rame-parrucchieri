# Rame Parrucchieri

Website for a hair salon.

![Preview](.github/preview.jpg)

**Live:** [rame-parrucchieri.vercel.app](https://rame-parrucchieri.vercel.app)

## Stack

Next.js, TypeScript, Tailwind CSS, GSAP, Framer Motion

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.
